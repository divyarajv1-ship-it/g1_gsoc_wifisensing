# Data

This project uses **no external dataset**. All data are generated by the scripts in `Code/src/` with fixed seeds, so every number can be regenerated exactly.

| Data | Generated by | How |
|---|---|---|
| Transmitted packets | all experiments | bytes 0–1 = 16-bit sequence number, rest uniform random bytes; seeds 1–5 (1–3 in E8b); 3 unscored flush packets |
| Baseband OFDM signal | GNU Radio `ofdm_tx` | FFT 64, CP 16, BPSK header/payload, CRC32, scrambling on; rolloff 0/1/2/4 or zero-sample gaps |
| AWGN | GNU Radio Channel Model (M2) / numpy (M3) | SNR = mean TX sample power ÷ noise power |
| Multipath | `m3_harness.py` | exponential power-delay profiles with 1, 3, 8, 14 taps (rms delay ≈ 0, 35, 100, 200 ns at 20 MHz); kept shorter than the CP |
| CFO | `m3_harness.py` | 0–3.5 subcarrier spacings |
| Time-varying channel (sensing) | `e9_csi_sensing.py` | 8 static taps + one reflector whose gain/phase oscillate at 0.5 Hz; 50 packets/s, 500 packets |
| Trigger positions, channel estimates | `ofdm_rx(debug_log=True)` | read from `sync-detect.dat` and `channel-estimate.dat` |

Results of every run are in `../Results/` (CSV + logs). To regenerate: `bash ../Code/run_all.sh`.

**Benchmark mentioned in M1 (SenseFi).** We did not need SenseFi data: E9 measures sensing error on a controlled synthetic channel where the true motion frequency is known. Feeding GNU Radio CSI into SenseFi-format datasets is part of the GSoC 2027 proposal.
