# Data — Milestone 1

## Status

No project dataset or experimental data is included in Milestone 1.

The M1 work focused on:

- Understanding Wi-Fi sensing and Channel State Information (CSI).
- Reviewing existing Wi-Fi sensing research.
- Studying GNU Radio OFDM and channel-processing components.
- Investigating GNU Radio Issues [#7997](https://github.com/gnuradio/gnuradio/issues/7997) and [#6891](https://github.com/gnuradio/gnuradio/issues/6891).
- Defining the experimental setup and evaluation plan for subsequent milestones.

## Planned Dataset

For later application-level Wi-Fi CSI sensing evaluation, the project plans to use the **SenseFi Wi-Fi CSI Sensing Benchmark**.

[SenseFi Wi-Fi CSI Sensing Benchmark](https://github.com/xyanchen/WiFi-CSI-Sensing-Benchmark)

SenseFi provides publicly available Wi-Fi CSI sensing datasets and implementations of established sensing models.

The datasets considered for future evaluation include:

- **UT-HAR** — Human Activity Recognition
- **NTU-Fi HAR** — Human Activity Recognition
- **NTU-Fi HumanID** — Human Identification
- **Widar** — Wi-Fi sensing and gesture recognition

SenseFi will be used for application-level validation after the OFDM and channel-processing pipeline has been established and evaluated.

## M1 Data Status

No SenseFi dataset has been copied into this repository during Milestone 1 because dataset-based sensing experiments are planned for a later milestone.

Large external datasets, when required, will be obtained directly from their respective public sources rather than stored in this repository.
